# Upstream provenance

Ableton MCP Extended is a derivative of:

- Project: `ahujasid/ableton-mcp`
- Repository: https://github.com/ahujasid/ableton-mcp
- Base commit: `5e9ffbd246bae60994699900f4fef34ad7b40407`
- Base version: `1.2.0`
- Upstream author: Siddharth Ahuja
- License: MIT

The clean derivative retains the upstream Git history and the original license.
The extended work was compared against the base commit above; local deployment
caches, machine-specific paths, runtime identifiers, bytecode, and the earlier
experimental repository structure were deliberately excluded.

The repository has two remotes in maintainer checkouts:

- `upstream`: the original project
- `origin`: this derivative

That naming makes future upstream synchronization and attribution explicit.
