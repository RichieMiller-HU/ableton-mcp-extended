# Contributing

Contributions should be small, reviewable, and tied to real behavior changes.
Do not create empty, generated, backdated, or otherwise artificial commits.

Before opening a pull request:

1. Preserve upstream attribution and the MIT license.
2. Add or update tests for the behavior being changed.
3. Run the unit suite, offline secret scan, and package build.
4. Test Live API changes in a disposable Ableton set and report the Live
   version used.
5. Keep secrets, personal paths, logs, audio projects, and generated bytecode
   out of the repository.
